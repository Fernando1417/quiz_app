# Requirements

Questions defined as an array of objects (no hard-coded HTML per question).  
Render questions and options with DOM manipulation.  
Track the score; show right/wrong feedback per answer.  
A results screen with the final score and a restart button.  
Three screens to implement:  
Start: you can either answer trivia or edit questions  
Trivia: you answer the stored questions and the app shows your score at the end, with option to start over  
Edit questions: you can edit the questions and answers, or add new ones  
Everything's stored in memory objects.

Full details https://youtu.be/km9hWtzHAYU?t=3233  
Evaluación:  
50% edición de preguntas: editar actuales, agregar nuevas, editar opciones y opción correcta  
30% responder preguntas: ver progreso, pantalla final, reintentar  
20% estilos, estructura general, pantalla de inicio, poder reiniciar
